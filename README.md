# 中国夏季东南季风概率分析工具

基于李建平团队发布的 **SCSMI（南海夏季风指数，South China Sea Summer Monsoon Index）**
历史序列，结合 NOAA CPC 的 **ONI / SOI** 指数与 NOAA PSL 的 **DMI**（印度洋偶极子）
指数，估计未来夏季（6–9 月，JJAS）
**偏强 / 正常 / 偏弱** 三种状态的出现概率。与姊妹项目 `enso-probability` 同一架构，
纯 Python 标准库实现，无第三方依赖。

## 快速开始

```bash
# 抓取并缓存 SCSMI / ONI / SOI / DMI 五源数据（写入 data/）
python monsoon_prob.py update

# 输出概率预测（默认按当前日期自动选择起报月）
python monsoon_prob.py forecast

# 同时把预测结果写入 output/forecast.json
python monsoon_prob.py forecast --json

# 查看各起报月 × 提前期的样本外回测技能面板
python monsoon_prob.py backtest

# 生成可视化 HTML 报告（概率卡 + 相似年份 + 逐月强度点预测 + 技能热力图 + 可靠性校准）
python monsoon_prob.py report

# 生成可供 GitHub Pages 托管的静态报告
python monsoon_prob.py report --out docs/index.html

# 运行内置自测
python monsoon_prob.py selftest
```

需要 Python 3.9+。没有网络时可加 `--offline` 直接用 `data/` 下的缓存。

## 目标变量与状态判定

| 项目 | 说明 |
| --- | --- |
| 指标 | 南海夏季风指数 SCSMI（Li & Zeng 2002/2003/2005 统一季风指数框架，DNS 动力学标准化季节变率），取 6–9 月（JJAS）标准化值 |
| 物理含义 | 度量南海季风区低层环流季节性反转强度，是中国东南部夏季风（东南季风）的直接强度指标 |
| 区间 | 1948 年至今（约 78 年样本），逐年 |
| 判定 | JJAS 标准化值 `>= +0.5σ` → **偏强**；`<= -0.5σ` → **偏弱**；其余 → **正常** |

## 起报约定

- 起报月 `m` 在 1–12 月均可；
- `m ≤ 5` 时预报**同年** JJAS（提前 5→1 个月），`m ≥ 6` 时预报**次年** JJAS（提前 12→6 个月）；
- 提前期 = 距目标夏季 6 月的月数。1–5 月为常规业务起报窗口，其余月份属于超长期展望，
  终端与报告中会明确提示技能随提前期衰减。

## 方法

三个环节相互交叉验证，最终按历史技能加权。

### 1. 状态转移模型

在"上一个夏季（去年 JJAS）状态 + 起报时 ENSO 态"的联合条件下，
统计今年夏季的状态频率：条件计数 + Dirichlet 先验（强度 = 4 × 历史边际频率），
起报月分层与全历史估计按 `λ = n/(n+24)` 做经验贝叶斯收缩——同月起报样本越少，
越回退到全历史估计，抑制小样本方差。

### 2. 历史相似型模型

以 19 维特征（起报前 6 个月 ONI 轨迹 + 6 个月 SOI 轨迹 + 6 个月 DMI 轨迹 +
去年夏季 SCSMI 持续性）为查询向量，在过去所有年份上做**滚动标准化**后的
按维度归一欧氏距离匹配，高斯核 `exp(-d² / 2bw²)` 加权（Silverman 带宽，下限 0.35），
统计各近邻当年 JJAS 状态频率。

- 候选年严格早于目标年，滚动标准化只使用候选期自身统计量——不存在未来信息泄漏；
- 前一年 SCSMI 特征依赖源站点发布（滞后约一年），DMI/SOI 缺失时自动逐级降维
  （去 DMI → 去 SOI → 去前一年 → 仅 ONI）并在报告中提示；
- DMI（印度洋偶极子）影响南海季风爆发与盛期对流，加入该轨迹可更好匹配
  热带印太耦合背景相似的历史年份。

### 3. 组合权重

从 1948 年起逐年滚动做样本外回测，计算三分类 Brier 技能分
`Skill = 1 - BS_model / BS_climatology`，权重按正技能分分配；
负技能模型剔除，两模型均不优于气候态时退化为等权并提示。

### 4. 相似年份透明化与逐月强度点预测

报告列出与当前特征最相似的 5 个历史年份及它们其后夏季的实际状态和标准化值，
并用近邻对 6/7/8/9 月与 JJAS 做加权点预测（均值 + 加权 5%/95% 分位作为 90% 区间），
给出强度曲线而不只是三态概率。

### 5. 不确定性区间

90% 区间来自 Dirichlet 后验蒙特卡洛抽样（固定种子 1500 次）。

### 6. 逐月三档概率与偏强月数分布

6/7/8/9 月各自的三档概率由相似型近邻对**当月**标准化值加权计票 + Dirichlet 后验 90% 区间得到，
另有"偏强月数（≥+0.5σ 的月数）"加权分布——季节平均态会掩盖月内反向信号（爆发早 / 结束晚），
逐月概率与之互为补充。报告同时给出逐月三档概率的历史校准表（样本量、逐月 Brier 技能、气候态频率），
逐月技能与总体一样为负，仅作结构展示。

### 7. 诊断面板

- **技能热力图**：12 个起报月 × 对应提前期的组合模型 Brier 技能分（绿=有技能，红=负技能）；
- **可靠性曲线**：历史组合预测概率分 10 桶，横轴=预测概率、纵轴=桶内实际频率，
  点越贴近对角线概率越校准。

### 8. 南海季风爆发日期（第一次北跳）

以区域 (10°-20°N, 110°-120°E)（南海中北部，主流文献与业务监测口径）850 hPa 纬向风
候平均值由负转正、且其后连续 2 候
维持正值（王斌等 2004 判定标准）推算每年南海季风爆发候——即"东亚夏季风第一次北跳 /
南海季风建立"的日期，与逐月强度预测互为补充（季节平均态会掩盖爆发早晚）。

- 历史序列由 NCEP/NCAR R1 逐日再分析推算（抓取见"数据"表），统计均值 / 最早 / 最晚 /
  线性趋势 / 滞后 1 年自相关，以及与 DJF ONI、4 月 SOI 的同期相关；
- 对目标年给出两类预测：**相似型近邻加权**（含 90% 分位区间）与**线性回归**
  （DJF ONI + 4 月 SOI + 前一年爆发候）；
- 逐年只用当年之前的数据做样本外验证（起报 4 月口径），报告相关系数、MAE、
  相对气候态的 MAE 技能与距平符号命中率。若 MAE 技能为负，则爆发日期预测
  不优于直接使用气候态日期，会在报告中如实标注。

### 9. 转折诊断面板（应对季风"跳跃"）

夏季风并非渐变——南海季风爆发本身就是一次状态跳跃，季节平均态同样存在持续年与
转折年之别。把全部（起报月 × 验证年）回测样本按**前一年状态 == / != 当年实际状态**
分两层（分层只用前一年状态，起报时已知，无未来泄漏），分别统计组合模型的
Brier 分与 Brier 技能：

- **持续年**（今年状态=去年状态）：模型主要靠持续性"得分"的层；
- **转折年**（今年状态≠去年状态）：状态跳跃发生年，滞后类统计模型的软肋。

实测：持续年技能分略低于/接近气候态，转折年约 -0.19——即模型技能几乎全部来自
持续性，遇到状态跳跃即滞后失效。该表随报告与 `backtest` 子命令输出，
是理解"转折年概率需谨慎解读"的直接证据。

### 10. 因子分层与年代际非平稳诊断

**ENSO 发展阶段分层**：把全部（起报月 × 验证年）回测样本按起报时点的 ENSO 发展阶段
分层统计组合 Brier 技能。阶段由起报月（含）之前的 3 个月 ONI 趋势判定
（变化 ≥ +0.2 → 发展、≤ -0.2 → 衰减、平缓 → 峰值，近 6 个月 |ONI| 全 < 0.5 → 中性），
只用起报时已知数据，无未来泄漏。实测各阶段技能差异显著（中性约 -0.10，
ENSO 成熟/峰值约 -0.24）——印证 ENSO 成熟期遥相关弱、可预报性存在
"春季预报障碍"式阶段差异，跨阶段合并统计会掩盖该信号。

**年代际滚动窗**：以 30 年窗、5 年步长逐年滑窗重算组合 Brier 技能，检验可预报性的
年代际非平稳。实测技能从 1950 年代的约 -0.32 逐步改善到 1970–2000 年代的接近 0，
随后回落至约 -0.13——预报因子与季风的耦合强度随年代变化，整体平均会掩盖窗口差异。

## 局限性

- 概率完全来自历史统计外推，**不等于官方季节预报**，也不构成任何决策依据；
- 当前样本（约 74–78 年）上回测三分类 Brier 技能为负，多数月份不优于气候态，
  只能作为临近夏季时的定性参考；
- 转折诊断显示：模型技能几乎全部来自持续性年，状态跳跃（转折）年技能显著为负
  （约 -0.19），起报于转折年的概率需比其他年份更谨慎解读；
- 因子分层显示：ENSO 发展阶段间可预报性差异大（成熟/峰值期最差，约 -0.24），
  处于峰值期的起报结果尤其不可靠；年代际窗显示技能随时间先升后降，
  1970–2000 年代接近 0、其余年代更差，可预报性存在年代际非平稳；
- SCSMI 由源站点在每个夏季结束后更新，存在约一年滞后，最近目标年的真值不可得，
  且"前一年 SCSMI"特征随之缺降维；
- 模型只使用 ONI/SOI/DMI 与季风持续性，未纳入次表层海温、高原积雪、
  印度洋-太平洋耦合过程、台风活动等信息；
- 爆发日期由 NCEP/NCAR R1 再分析推算：该资料已于 2026 年 3 月停产，
  序列暂止于 2025 年；再分析为 2.5° 粗网格，个别年份（如 2018 年）与官方
  业务判定可能相差 1-3 候；
