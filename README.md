# 中国夏季东南季风概率分析工具

基于李建平团队发布的 **SCSMI（南海夏季风指数，South China Sea Summer Monsoon Index）**
历史序列，结合 NOAA CPC 的 **ONI / SOI** 指数，估计未来夏季（6–9 月，JJAS）
**偏强 / 正常 / 偏弱** 三种状态的出现概率。与姊妹项目 `enso-probability` 同一架构，
纯 Python 标准库实现，无第三方依赖。

## 快速开始

```bash
# 抓取并缓存 SCSMI / ONI / SOI 三源数据（写入 data/）
python monsoon_prob.py update

# 输出概率预测（默认按当前日期自动选择起报月）
python monsoon_prob.py forecast

# 同时把预测结果写入 output/forecast.json
python monsoon_prob.py forecast --json

# 查看各起报月 × 提前期的样本外回测技能面板
python monsoon_prob.py backtest

# 生成可视化 HTML 报告（概率卡 + 相似年份 + 逐月强度点预测 + 技能热力图 + 可靠性校准）
python monsoon_prob.py report

# 生成可供 GitHub Pages 托管的静态报告
python monsoon_prob.py report --out docs/index.html

# 运行内置自测
python monsoon_prob.py selftest
```

需要 Python 3.9+。没有网络时可加 `--offline` 直接用 `data/` 下的缓存。

## 目标变量与状态判定

| 项目 | 说明 |
| --- | --- |
| 指标 | 南海夏季风指数 SCSMI（Li & Zeng 2002/2003/2005 统一季风指数框架，DNS 动力学标准化季节变率），取 6–9 月（JJAS）标准化值 |
| 物理含义 | 度量南海季风区低层环流季节性反转强度，是中国东南部夏季风（东南季风）的直接强度指标 |
| 区间 | 1948 年至今（约 78 年样本），逐年 |
| 判定 | JJAS 标准化值 `>= +0.5σ` → **偏强**；`<= -0.5σ` → **偏弱**；其余 → **正常** |

## 数据

| 文件 | 来源 | 说明 |
| --- | --- | --- |
| `data/scsmi_cache.txt` | 李建平团队 [lijianping.cn](http://lijianping.cn/dct/page/65578)（ASCII:876） | SCSMI 原始值 + 标准化值，逐月 |

## 起报约定

- 起报月 `m` 在 1–12 月均可；
- `m ≤ 5` 时预报**同年** JJAS（提前 5→1 个月），`m ≥ 6` 时预报**次年** JJAS（提前 12→6 个月）；
- 提前期 = 距目标夏季 6 月的月数。1–5 月为常规业务起报窗口，其余月份属于超长期展望，
  终端与报告中会明确提示技能随提前期衰减。

## 方法

三个环节相互交叉验证，最终按历史技能加权。

### 1. 状态转移模型

在"上一个夏季（去年 JJAS）状态 + 起报时 ENSO 态"的联合条件下，
统计今年夏季的状态频率：条件计数 + Dirichlet 先验（强度 = 4 × 历史边际频率），
起报月分层与全历史估计按 `λ = n/(n+24)` 做经验贝叶斯收缩——同月起报样本越少，
越回退到全历史估计，抑制小样本方差。

### 2. 历史相似型模型

以 13 维特征（起报前 6 个月 ONI 轨迹 + 6 个月 SOI 轨迹 + 去年夏季 SCSMI 持续性）
为查询向量，在过去所有年份上做**滚动标准化**后的欧氏距离匹配，
高斯核 `exp(-d² / 2bw²)` 加权（Silverman 带宽，下限 0.35），统计各近邻当年 JJAS 状态频率。

- 候选年严格早于目标年，滚动标准化只使用候选期自身统计量——不存在未来信息泄漏；
- 前一年 SCSMI 特征依赖源站点发布（滞后约一年），缺失时自动降维并在报告中提示。

### 3. 组合权重

从 1948 年起逐年滚动做样本外回测，计算三分类 Brier 技能分
`Skill = 1 - BS_model / BS_climatology`，权重按正技能分分配；
负技能模型剔除，两模型均不优于气候态时退化为等权并提示。

### 4. 相似年份透明化与逐月强度点预测

报告列出与当前特征最相似的 5 个历史年份及它们其后夏季的实际状态和标准化值，
并用近邻对 6/7/8/9 月与 JJAS 做加权点预测（均值 + 加权 5%/95% 分位作为 90% 区间），
给出强度曲线而不只是三态概率。

### 5. 不确定性区间

90% 区间来自 Dirichlet 后验蒙特卡洛抽样（固定种子 1500 次）。

### 6. 诊断面板

- **技能热力图**：12 个起报月 × 对应提前期的组合模型 Brier 技能分（绿=有技能，红=负技能）；
- **可靠性曲线**：历史组合预测概率分 10 桶，横轴=预测概率、纵轴=桶内实际频率，
  点越贴近对角线概率越校准。

## 自测

`python monsoon_prob.py selftest` 共 91 项，全部通过：

| 类别 | 检查 |
| --- | --- |
| 解析 | SCSMI 原始/标准化列解析与 99.99 缺失值处理 |
| 规则 | ±0.5σ 三档判定、JJAS 提取、起报月→目标年映射（m≤5 / m≥6 边界） |
| 无泄漏 | 转移模型训练行严格早于目标年、相似候选严格早于目标年 |
| 参数回收 | 合成转移模型上条件概率误差受限 |
| 蒙特卡洛对照 | 合成序列上相似型加权与 Dirichlet 区间覆盖 |
| 符号翻转 | 翻转 SCSMI 序列符号后偏强/偏弱概率严格互换 |
| 统计性质 | 概率归一、分位有序、区间覆盖点估计、λ 收缩单调性 |
| 窗口 | 起报前轨迹窗口长度、跨年月份归一、完整/边界窗口闭区间语义 |
| 回测 | Brier 技能解析式与逐桶自洽 |
| 校准 | 每起点恰入一桶、空桶安全渲染 |
| 可视化 | 概率卡/点预测 SVG/历史 SVG/校准 SVG/热力表片段生成正确 |

## 局限性

- 概率完全来自历史统计外推，**不等于官方季节预报**，也不构成任何决策依据；
- 当前样本（约 74–78 年）上回测三分类 Brier 技能为负，多数月份不优于气候态，
  只能作为临近夏季时的定性参考；
- SCSMI 由源站点在每个夏季结束后更新，存在约一年滞后，最近目标年的真值不可得，
  且"前一年 SCSMI"特征随之缺降维；
- 模型只使用 ONI/SOI 与季风持续性，未纳入次表层海温、高原积雪、
  印度洋-太平洋耦合、台风活动等信息；
- SCSMI 与区域降水的相关并非 1:1，**不能当作降水预报直接使用**；
- 1948 年之前的样本缺失，早期观测精度低于卫星时代。
